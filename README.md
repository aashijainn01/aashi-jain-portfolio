## 🚀 Overview

This repository contains the source code for my personal developer portfolio. It was designed to push the boundaries of standard web portfolios by incorporating immersive interactive elements, 60fps animations, and a cyberpunk-meets-minimalist aesthetic. It serves as the digital home for my projects, skills, and experience as a **Java Backend Developer** and **AI Integration Enthusiast**.

**🔗 Live Demo:** [portfolio.aashijain.com](https://your-live-link-here.com) *(Add your live link here)*

## ✨ Key Features

- 🌌 **Immersive Aurora Hero Section:** Deep space void background with slow-moving aurora gradient meshes and particle interactions.
- 💻 **Terminal Typewriter:** A pseudo-code terminal window demonstrating my core tech stack with syntax highlighting.
- 🌠 **Interactive Skill Constellation:** A unique galaxy-style map representing my technical skills instead of traditional progress bars.
- 🎴 **Holographic Project Cards:** 3D tilt effects (`rotateX`, `rotateY`) combined with mouse-tracked holographic conic gradients.
- 🧲 **Magnetic UI Elements:** Call-to-action buttons that organically pull towards the user's cursor.
- 🌓 **Dynamic Theming:** Seamless switching between customized color palettes (Violet, Cyan, Rose).
- 📱 **Fully Responsive:** Carefully crafted layouts for Mobile, Tablet, and Desktop displays.

## 🛠️ Built With

## 💻 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites
Make sure you have Node.js and npm installed.
- [Node.js](https://nodejs.org/) (v16.x or later)
- npm (v7.x or later)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/aashijainn01/portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.
